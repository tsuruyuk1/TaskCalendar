# Календарь задач (Android, Kotlin)

Семестровый проект по мобильной разработке: приложение «Календарь задач» с локальным хранением данных.

**Стек:** Kotlin, Android Views (XML) + Material 3, Room, MVVM, Coroutines/Flow. minSdk 26.

## Статус этапов
| Этап | Содержание | Статус |
|---|---|---|
| 1 | Настройка окружения, экран-заглушка | + |
| 2 | Список задач (RecyclerView), FAB, переходы между экранами | + |
| 3 | Локальная база данных Room, CRUD, тестовый экран «Отладка БД» | + |

## Сборка
1. Установить Android Studio (актуальная стабильная версия) и JDK 17 (поставляется со Studio).
2. `File → Open` → выбрать папку проекта, дождаться Gradle Sync.
3. Выбрать эмулятор или устройство и нажать **Run ▶**.

Документы к этапам лежат в папке [`docs/`](docs/).
